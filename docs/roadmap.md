# 다음 작업

[문서 목록](README.md) · [현재 동작과 한계](architecture/agent-workflow.md)

## 구현된 범위

- Grafana MCP의 읽기 전용 지표·로그 수집과 고정 보고서 v3.
- 합성 사례를 이용한 고정 보고서 평가와 선택적인 Langfuse 기록.
- 다음 도구 또는 종료를 선택하는 LangGraph 조사 루프.
- 조사별 근거·판단 기록, 예산 보존, SQLite 체크포인트와 중단·재개.
- 소스 패키지 분리와 공개 문서·개인 문서 분리.

조사 루프의 완료나 자동 테스트 통과는 모델 해석의 정확성 확인이 아닙니다.
현재 Agent는 자연어의 시간·대상 추출, 후속 대화, 장기 메모리, Sentry·코드 조회를 지원하지 않습니다.

## 가까운 작업 순서

1. 요청 계약: 서비스·환경·시간대·조회 구간·증상을 구조화하고 실제 쿼리에 반영합니다.
   모호한 요청의 확인 절차, 지원하지 않는 범위, 기본값 표시를 정의합니다.
2. 사용자용 보고서: 기존 JSON의 사실·가설·한계·출처를 Markdown으로 표시합니다.
   표시를 위해 별도 모델 호출을 추가하지 않습니다.
3. 조사 범위 확장: 실제 계측된 HTTP 요청량·오류율·지연 등의 한 영역을 선택합니다.
   공통 도구 정의와 요청 유형별 라우팅, 단위·관측 범위, 보고서 최소 근거 정책을 함께 확장합니다.
4. Agent 비교 평가: 같은 사례로 고정 흐름과 비교합니다. 근거 정확도, 조기 종료,
   불필요한 조회, 근거 없는 주장, 지연·실제 토큰을 측정하고 예산을 조정합니다.
5. 추가 근거: 배포 커밋 기준 코드 조회를 연결합니다. Sentry 계측이 있다면 이슈·이벤트
   조회를 추가 후보로 평가하고 Grafana 근거와 같은 환경·시간·trace 기준으로 연결합니다.

새 조사 기능마다 합성 오류·빈 결과·정상 결과를 평가하고, 같은 질문에서 이전 방식보다
관련 근거와 다음 확인 지점을 더 정확히 찾는지 비교합니다.
