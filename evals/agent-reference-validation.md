# Agent 근거 참조 검증

2026-09-27, `qwen2.5:3b`와 `ops_agent_v3`를 사용해 이전 실패 시점에 저장한
실제 Prometheus·Loki 요약으로 판단 한 단계를 실행했습니다. Grafana를 새로 조회하거나
전체 조사 루프를 실행한 실험은 아닙니다. 원본 입력·응답은 Git에서 제외된 `artifacts/`에 보존합니다.

이전 실행에서는 `no_data`인 로그 근거를 가설에 인용해 검증에서 거부됐습니다.
새 버전은 생성 스키마의 근거 ID를 `data_available` 목록으로 제한하고, 검증 실패 시
같은 예산 안에서 한 번만 수정 요청합니다. 각 응답과 검증 결과는 별도로 보존합니다.

| 검사 | 이번 결과 |
|---|---|
| JSON 형식·허용된 도구·근거 ID | 통과 |
| 모델 호출 | 1회, 수정 요청 발생하지 않음 |
| 입력·출력 토큰 | 3,012 / 261 |
| 가설의 근거 적합성 | Codex 검토에서 미충족 |
| Langfuse 서버 수신 | 부모·모델 응답·검증 metadata 확인 |

모델은 이번에 유효한 지표 ID를 인용했지만, 요청률 지표로부터 “경고 또는 오류 로그가
존재한다”고 주장했습니다. 이 지표는 해당 주장을 뒷받침하지 않습니다. **참조 검증 통과는
가설 정확성 통과가 아닙니다.** 자동 수정은 검증에서 실패한 응답에만 적용되므로 이번
의미적 오류에는 실행되지 않았습니다.

Langfuse에는 `auto_agent_reference_validity=1`과
`codex_hypothesis_support_review=0`을 구분해 기록했습니다. 후자는 Codex의 정성 검토이며
독립적인 사람 평가나 일반적 모델 정확도 점수가 아닙니다. 프롬프트·입력·스키마가 함께
변경됐고 한 사례를 한 번 실행했으므로 개별 변경의 효과나 전체 품질 향상을 주장하지 않습니다.

자동 회귀 검사는 수정 성공·수정 재실패·예산 소진·입력 크기 초과·근거 없는 상태에서의
빈 가설 제한·추적 오류 코드를 다룹니다. 수정 경로는 mock 응답으로 검증했습니다.
