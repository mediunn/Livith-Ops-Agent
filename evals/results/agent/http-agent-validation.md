# HTTP 조사 검증

[평가 방법](../../README.md) · [실행 안내](../../../docs/usage.md)

HTTP 수집·후속 조회·중단·재개 경로는 구현되어 있습니다.
실제 Grafana 연결은 확인했으며, **모델의 가설 갱신과 종료 판단 품질은 검증 중**입니다.

## 실제 연결·재개

규칙 planner로 GET `/api/v7/recommendation//concerts`의 요청률과 평균 지연을 조사했습니다.
현재 구간은 2026-09-26 12:00~2026-09-27 12:00 UTC, 비교 구간은 같은 길이의 직전 구간입니다.

| 항목 | 결과 |
|---|---|
| 현재·직전 요청률과 평균 지연 | 네 조회 모두 `data_available` |
| 조회 후 저장·SQLite 재개 | 완료 |
| 최종 상태 | `completed`, `planner_finished` |
| 도구 / 모델 호출 | 4 / 0 |
| MCP 세션 | 실행·재개 각각 한 세션, 정상 종료 |

이는 연결·파싱·조회 조건·재개 검증입니다. 실제 운영 데이터에 대한 LLM 판단 검증과는 구분합니다.
실행 ID는 `e2144e67a7d6474e9d6dfe47672cbc1f`이며 README의 결과 예시는 이 보고서의 발췌입니다.

## 모델 평가

2026-09-28, 개발용 합성 사례를 실제 로컬 모델과 HTTP 조사 그래프에 통과시켰습니다.
비교 사례는 지연 증가, 요청률 0으로 감소, 증가 의심 반박의 세 종류입니다.
빈 데이터 사례는 코드가 처리하므로 아래 모델 판단 분모에서 제외했습니다.

모델은 `qwen2.5:3b`와 `huihui_ai/qwen2.5-abliterate:14b-instruct`입니다.
후자는 수정 모델이므로 파라미터 수만 다른 실험이 아닙니다. 공통 설정은 조사 300초,
모델 호출당 90초, 도구 6회, 모델 8회, temperature 0, 컨텍스트 16,384, 출력 상한 1,024입니다.

| 입력 구성 | 모델별 반복 | 모델 | 필요한 직전 조회 | 마지막 가설 상태·양쪽 인용 | 시간 초과 |
|---|---:|---|---:|---:|---:|
| 전체 관측·판단 이력 | 2회 | 3B | 0/6 | 0/6 | 0/6 |
| 전체 관측·판단 이력 | 2회 | 14B | 6/6 | 0/6 | 0/6 |
| 새 근거·직전 조회 연결 표시 포함 | 1회 | 3B | 0/3 | 0/3 | 0/3 |
| 새 근거·직전 조회 연결 표시 포함 | 1회 | 14B | 3/3 | 1/3 | 3/3 |

현재 입력은 새 근거 연결 표시를 포함합니다. 이 구성에서 3B는 두 사례에서 잘못된 선택으로,
한 사례에서는 필요한 직전 비교 없이 종료했습니다. 14B는 세 사례 모두 직전 조회 후 후속
모델 호출이 시간 초과되어 미완료로 끝났습니다. 두 모델의 빈 데이터 사례는 모델 호출 없이 종료했습니다.

가설 상태·양쪽 인용은 마지막으로 반영된 가설의 기계 검사입니다. 14B의 1/3도 **미완료
보고서**에서 계산됐으며 조사 성공을 의미하지 않습니다. 해당 문장은 “감소했는지 확인”이라는
조사 과제에 머물렀습니다. 원문 검토에서는 비교 전 단정, 모순된 가설, 불필요한 조회 지속도 확인됐습니다.

반복 평가의 동일 지연 사례에서는 반대 근거를 받은 뒤에도 증가 가설을 유지했습니다.
연결 표시를 포함한 실행의 동일 지연 사례는 후속 응답을 받지 못해 반박 판단을 평가할 수 없었습니다.
근거 ID가 존재하거나 새 ID를 인용하는 것만으로 비교 해석의 정확성을 보장하지 않습니다.

## 해석 범위

개발에 사용한 작은 사례 집합의 내부 평가입니다. 가설 문장 검토는 자동 검사와 구분하며
`semantic_review`는 `pending`으로 유지합니다. 입력 구성별 실행 횟수·UUID·로컬 부하가 달라
이 결과만으로 변경의 효과나 모델의 일반 성능 우열을 확정하지 않습니다.
규칙 planner도 증상을 해석하지 않는 기준선이므로 모델 우월성을 주장하는 비교군으로는 제한적입니다.

조회 선택은 평가할 수 있지만, 가설 갱신·반박·적절한 종료의 신뢰성 개선은 입증되지 않았습니다.
기본 모델과 예산은 유지하며 판단 품질은 현재 지원 범위의 한계로 명시합니다.
