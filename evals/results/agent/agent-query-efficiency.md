# 외부 API 조사 검증

[평가 방법](../../README.md) · [실행 안내](../../../docs/usage.md)

외부 API 조사는 필수 지표·로그 수집, 관측 보존, 로그 완전성에 따른 추가 조회 정책을
검증했습니다. 모델의 자유로운 원인 분석 대신 코드가 정한 조사 계약의 이행을 평가합니다.

## 합성 사례

2026-09-27, `qwen2.5:3b`, 프롬프트 `ops_agent_v8`, 정책 `investigation-policy-v2`,
상태·보고서 v4로 일곱 개발 사례를 두 번씩 실행했습니다. 합성 MCP 관측을 파싱한 뒤
실제 모델·planner·LangGraph·SQLite·예산·보고서 경로를 사용했습니다.

| 사례 | 추가 경고 조회 | 도구 / 모델 호출 (각 실행) | 자동 조건 |
|---|---|---|---|
| 요청률 0, 로그 없음 | 생략 | 3 / 3 | 2/2 통과 |
| 요청률 증가 | 생략 | 3 / 3 | 2/2 통과 |
| 경고 존재, 로그 잘림 | 수행 | 4 / 4 | 2/2 통과 |
| warn/error 문자열을 포함한 info 로그 | 생략 | 3 / 3 | 2/2 통과 |
| 잘린 info 로그 밖의 경고 | 수행 | 4 / 4 | 2/2 통과 |
| 로그 완전성 정보 없음 | 수행 | 4 / 4 | 2/2 통과 |
| 완전한 로그에 경고 존재 | 생략 | 3 / 3 | 2/2 통과 |

14회 모두 필수 조회·관측 보존·추가 조회 조건 등 10개 자동 조건을 통과했습니다.
이는 제한된 선택 공간에서의 정책 준수 결과이며 모델의 일반적인 조사 정확도 점수가 아닙니다.
데이터셋은 개발에 사용한 내부 평가 사례입니다.

## 실제 Grafana 확인

현재·직전 요청률과 서비스 로그를 조회하고 추가 경고 조회를 생략했습니다.
지표는 각 3개 시계열·93개 샘플에서 모두 0, 로그는 `no_data`였습니다.
필수 조회를 마친 결과는 `completed`, 관측 분류는 `insufficient_evidence`,
건강 상태는 `not_evaluated`였습니다. 도구·모델은 각각 3회 호출했습니다.

Langfuse에서 실제 실행과 합성 평가의 추적·자동 점수 수신도 확인했습니다.
운영 데이터가 0·빈 로그인 사례이므로 실제 장애 탐지 성능까지 검증한 결과는 아닙니다.

## 확인 범위

실행 제어 검사는 99/100건 경계, 완전성 정보 누락·불일치, 범위 이탈, 중복 조회,
잘못된 수치, 예산 소진과 별도 프로세스의 중단·재개를 포함합니다.
현재 지원 관측은 반환 로그의 경고·오류 레벨과 구간 마지막 요청률 증가입니다.
감소·원인 분석·서비스 정상 판정은 이 경로의 관측 정책에 포함하지 않습니다.
