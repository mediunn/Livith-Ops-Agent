실행일: 2026-09-28 (Asia/Seoul).

## 결과

총 8회 실행을 마쳤다. 새 근거 인용은 일부 확인했지만 **조사 품질 개선은 입증하지 못했다.**
비교가 필요한 세 사례에서 3B는 직전 구간을 조회하지 않았고, 14B는 모두 조회했지만
후속 모델 호출이 시간 초과됐다. 이번 변경만으로 가설 갱신·반박·종료 문제가 해결되지 않았다.

14B의 1/3은 **미완료 보고서의 마지막 가설**에 대한 상태·인용 검사다. 성공한 조사 수가 아니다.
3B의 `completed` 1회도 필요한 비교를 생략해 실패했다. 두 모델의 빈 데이터 사례는 모델 호출
없이 각각 정상 종료됐으며 표의 비교 분모에서 제외했다. CLI 종료 코드 1은 품질 검사 실패다.

14B 세 시간 초과는 모두 호출당 90초 제한에 걸렸다. 비교 구간을 조회하고도 최종 해석이
반환되지 않은 경우에는 반박 능력을 판정할 수 없다. 이전 실행의 무시간초과 결과와 차이는
있지만 로컬 부하·실행 시점이 통제되지 않아 입력 변경이 원인이라고 단정하지 않는다.
receipt의 추가 표시 크기는 160~1,620바이트였으며 전체 직렬화 입력은 최대 13,293바이트로
24,000바이트 제한 안이었다. 바이트 크기를 토큰 수로 해석하지 않는다.

## 원문 검토

- **3B 지연 증가:** 현재 구간의 뒤 절반을 조회한 뒤 같은 조건을 반복 선택하여 검증에 실패했다.
  최종 반영된 가설은 초기 근거만 인용했다.
- **3B 요청률 감소:** 직전 구간 없이 감소·감소하지 않음을 각각 `supported`로 남겼다.
  같은 조회를 반복 선택하여 종료됐다.
- **3B 증가 의심 반박:** 뒤 절반의 새 근거를 추가 인용하고 종료했지만 직전 구간을 조회하지
  않았다. 증가 가설을 계속 `supported`로 두어 비교와 반박에 실패했다.
- **14B 지연 증가:** 직전 지연을 조회하고 새 근거를 인용했지만 상태는 `insufficient_evidence`를
  유지했다. 앞 절반을 추가 조회한 뒤 다음 모델 호출이 90초 제한에 걸렸다.
- **14B 요청률 감소:** 직전 요청률을 얻고 현재·직전 근거를 함께 인용했다. 마지막으로 반영된
  가설은 `supported`지만 문장은 “0으로 감소했는지 확인”이라는 조사 과제다. 상태·인용 자동 검사는
  통과해도 비교 결론을 설명한 것으로 보지 않는다. 앞 절반 추가 조회 후 다음 호출이 시간 초과됐다.
- **14B 증가 의심 반박:** 직전 조회 전부터 증가를 `supported`로 두었다. 800ms → 800ms
  근거를 받은 뒤 호출이 시간 초과되어 새 근거에 대한 판단을 받지 못했다. 잘못된 초기 단정은
  확인했지만 이번 실행으로 새 근거를 보고도 기각하지 못했다고 결론내리지는 않는다.

검토자는 Codex이며 독립·블라인드 평가가 아니다. 자동 `semantic_review`는 계속 `pending`이다.

## 변경과 비교 조건

모델 입력에 `investigation_update`를 추가했다. 직전 판단 이후 새 근거 ID,
직전 조회의 조건·목적·결과 ID, 새 근거를 받기 전 가설을 함께 표시한다.
전체 관측과 판단 이력은 유지하며 조회·가설 상태·종료는 모델이 선택한다.
새 근거 표시는 모델이 그 근거를 읽거나 올바르게 해석했다는 판정이 아니다.

[이전 반복 평가](http-repeat-evaluation.md)의 실패를 바탕으로 한 개발 실험이다.
저장된 메타데이터 비교에서 실행 소스 변경은 `agent/http/context.py` 하나이며,
데이터셋 해시·프롬프트·출력 스키마·예산·생성 옵션은 동일하다.
조회 결과 연결은 지표 이름 대신 조회 조건 해시로 확인한다.

```bash
uv run python -m ops_agent.cli.evaluate_http_agent --planner llm \
  --models qwen2.5:3b huihui_ai/qwen2.5-abliterate:14b-instruct \
  --repeat 1 --seconds 300 --llm-seconds 90 --warmup
```

기존 네 사례를 모델별 한 번 실행한다. 이전 평가는 모델별 두 번이므로 횟수가 다르며,
근거 UUID·로컬 실행 부하도 달라질 수 있다. 동시에 실행한 대조군이나 독립 평가 세트는 아니다.
빈 데이터는 비교 사례 성공률에서 제외한다. 상태·양쪽 구간 인용 검사와 가설 문장 의미를
구분하고, 이번 결과만으로 일반 정확도나 변경의 인과 효과를 주장하지 않는다.
